# Rashi Singh's Portfolio

Welcome to my personal portfolio, a showcase of my journey as a full-stack developer passionate about crafting high-performing digital experiences. Built with the MERN stack and styled for impact, this site reflects my commitment to clean code, thoughtful design, and continuous learning.

## Live Demo

[View the live site](https://rashi-s-portfolio.vercel.app)

## Tech Stack

- **Frontend**: React (Create React App)
- **Styling**: CSS Modules
- **Icons**: Lucide React
- **Deployment**: Vercel
- **Version Control**: Git & GitHub

## Features

- Dynamic hero section and project showcase
- Resume download button
- GitHub and social links
- Custom favicon and branding
